## 6. Risks to watch

- Duplicate route registration and duplicate migration numbers will not fail a merge; only tests and review catch them.
- Applying migrations by tool name against staging means file numbers and history names can diverge; never use `supabase db push` from a fresh checkout until the history is reconciled (their own warning).
- Role RPC protects the last administrator; account deletion (ours) does not. Deleting the only admin would orphan the workspace.
- The workspace is built by string concatenation in `app.js`; confirm all dynamic values are escaped (their register control 7).
- Seven tabs on a 320 px bottom bar versus our a11y suite and the 44 px target rule.
- The merged tree is large; a stale offline cache (`ff-v8` vs `ff-v10`) can serve old shells. Bump the cache version in the merge commit.
